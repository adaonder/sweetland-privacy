# SweetLand Privacy Policy

Single privacy policy page for all SweetLand apps and games.

Live page: https://sweetlandapp.github.io/sweetland-privacy/

To add a new app: add a row to both tables and a section (English + Turkish) in `index.html`, then update the "Last updated" date.

Stand-alone pages: some stores (Huawei AppGallery) compare the linked policy
with the app's privacy tags, and a shared page listing other apps' data
collection reads as a mismatch. Such apps get their own page in a folder:

- `star-isles/` — Star Isles (source of truth: `star_isles/docs/privacy/index.html`)
